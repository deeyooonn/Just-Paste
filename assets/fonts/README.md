The app bundles these fonts so typography works without a network connection.

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

The original variable fonts are included as `Inter.ttf` and
`CormorantGaramond.ttf`. Their accompanying SIL Open Font Licenses are preserved
in this directory and registered with Flutter's license registry.
